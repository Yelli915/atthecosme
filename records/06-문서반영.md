# 6. 문서 반영 및 면접 준비

- 상태: 대기
- 대응: `계획.md` 6단계 / 기획서 전체
- 선행 조건: 1~5단계 완료 (또는 각 단계별로 [측정 예정] 유지 결정 완료)

## 체크리스트

- [ ] 측정 완료 항목의 표기를 [측정 예정] → [실측] / [구현]으로 변경
- [ ] 헤드라인 수치가 최종 측정값과 일치하는지 재확인
- [ ] 예상 질문 답변을 실제 구현 기준으로 작성
  - OCR 오탈자 시 검색이 실패하지 않는가 → 2단계 오탈자 집계로 답변
  - 성분 DB는 어디서 구축했는가 → 1단계 확인 내용으로 답변
  - 96.8%면 실무에 쓸 수 있는가 → 4·5단계 측정값으로 답변
- [ ] 오류 사례 이미지 3~4장을 바로 꺼낼 수 있게 정리

## 완료 기준 (계획.md)

- [ ] 기획서에 TODO가 남아 있지 않다
- [ ] 모든 [실측] 수치에 대해 원본 데이터나 로그를 제시할 수 있다
- [ ] 오류 원인별 실제 사례를 하나씩 보여줄 수 있다
