# records/

`계획.md`(Sprint 1 마무리 실행 계획)를 실제로 수행하면서 남기는 단계별 작업 기록.

## 파일 목록

| 파일 | 대응 단계 | 상태 |
| --- | --- | --- |
| [`00-setup.md`](./00-setup.md) | 사전 준비 (폴더 구조) | 완료 |
| [`01-사실정리.md`](./01-사실정리.md) | 계획.md 1단계 | 대기 |
| [`02-오류분석.md`](./02-오류분석.md) | 계획.md 2단계 | 대기 |
| [`03-대조구현.md`](./03-대조구현.md) | 계획.md 3단계 | 진행중 |
| [`04-신뢰도임계치.md`](./04-신뢰도임계치.md) | 계획.md 4단계 | 대기 |

## 규칙

- 각 파일은 작업을 시작할 때 상태를 `진행중`으로, 끝나면 `완료`(또는 시간 부족 시 `보류` + 사유)로 바꾼다.
- 체크리스트 항목은 `계획.md`에서 그대로 가져오되, 실제로 확인/측정한 **값과 근거(파일 경로, 로그, 명령어)**를 함께 적는다. 근거 없이 체크만 하지 않는다.
- 값을 못 채우면 항목을 미완으로 남기고 사유를 적는다 (계획.md 원칙: "측정하지 않은 값은 채우지 않는다").
- 각 단계 완료 시 `기획서.md`의 해당 TODO를 갱신하고, 이 로그에 "기획서 반영 완료" 표시를 남긴다.
