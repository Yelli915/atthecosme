- 상태: 진행중 (코드 작성 완료, 실제 이미지·벤치마크셋으로 미검증)
- 일시: 2026-09-24
- 계획.md 범위 밖 작업: 계획.md는 "코드가 이미 있다"는 전제로 사실 정리부터 시작했지만,
  실제로는 코드가 없었기 때문에(00-setup.md 참고) 이 단계에서 파이프라인 자체를 처음부터 구현했다.
  계획.md 1~6단계는 이 구현 이후에 진행한다.

## 스택 결정

| Stage | 선택 | 비고 |
| --- | --- | --- |
| 1. OCR | PaddleOCR (로컬) | `pipeline/ocr/engine.py` |
| 2. 하이브리드 검색 | SQLite + rank_bm25 + FAISS(sentence-transformers 임베딩) | `pipeline/retrieval/` |
| 3. 구조화 출력 | Ollama 로컬 LLM (`qwen2.5:7b`), JSON Schema `format` 파라미터로 Enum 제약 | `pipeline/structured_output/normalize.py` |
| 4. 대조 | 규칙 기반 ID 집합 비교 (누락/추가/불일치) | `pipeline/match/match.py` |
| 5. 신뢰도 분기 | 현재는 Stage 2 검색 점수만 사용 (임시), 임계치 0.90 플레이스홀더 | `pipeline/run.py`, `pipeline/config.py` |

## 확인한 것 (이번 세션에서 실제로 실행/검증)

- `python -m pipeline.retrieval.db` → SQLite DB 생성 및 15건 적재 확인 (`pipeline/retrieval/db.py`, stdlib만 사용해 의존성 설치 없이 검증 가능)
- 전체 `.py` 파일 `py_compile` 문법 검사 통과

### 2026-09-25 추가 확인

- 의존성 설치: `.venv`에서 `pip install -r requirements.txt` 완료 확인 (paddlepaddle 3.3.1, ollama 0.6.2 등). 단, 전역/사용자 Python으로 설치 시 `paddlepaddle`이 인덱스에서 아예 안 잡히는 문제가 있었음 — 반드시 프로젝트 `.venv` 활성화 후 설치해야 함.
- 로컬 LLM: `qwen2.5:7b` 대신 `ollama pull hf.co/Qwen/Qwen2.5-7B-Instruct-GGUF`로 받음 → 로컬 태그명이 `hf.co/Qwen/Qwen2.5-7B-Instruct-GGUF:latest`(3.0GB)로 달라져 `pipeline/config.py`의 `OLLAMA_MODEL`을 이 태그로 갱신함. README의 `qwen2.5:7b` 안내와 실제 사용 태그가 달라졌으므로 문서 갱신 필요.
- Stage 2+3 실동작 검증 (`ollama.chat` 실제 호출, 샘플 DB 15건 기준):
  - `나이아신아마이드` → 검색 1위 `Niacinamide` 정상 선택 (`chosen_ingredient_id=5`)
  - `히알루론산` → 이표기(alias) 경유로 `Sodium Hyaluronate` 정상 선택 (`chosen_ingredient_id=7`)
  - `존재하지않는가짜성분XYZ` → DB에 없는 성분을 후보 중 하나로 잘못 고르지 않고 `NOT_FOUND`로 정확히 거부 — 환각 방지(동적 Enum 제약) 의도대로 동작 확인
  - 근거: 임시 스크립트로 `HybridRetriever.search` + `normalize_token`을 이어서 실행, 원본 모델 응답(`raw_model_output`)까지 확인 (`{"ingredient_id": "cand_5"}` 등)

## 아직 확인 못한 것 (실 데이터 없음)

- Stage 1 (PaddleOCR) 실제 동작 — 실제 라벨 이미지가 아직 없어 미검증
- Stage 2 Dense 검색(FAISS) 자체는 위 스모크 테스트에서 간접 확인됐으나, 실제 라벨 OCR 결과(오탈자·부분 인식 포함)를 넣은 검증은 아님
- 실제 라벨 이미지, 실제 성분 마스터 DB(현재는 샘플 15건), 실제 벤치마크 manifest 전부 없음 → `eval/run_benchmark.py` 실행 불가, `run_pipeline()` 전체(Stage 1~5) 통합 실행 미검증
- Stage 5 신뢰도 결합에서 기획서가 언급한 "구조화 출력 토큰 로그 확률" 반영 안 함 — Ollama 응답에서 로그 확률을 받는 방법 확인 필요 (`pipeline/run.py` 주석 참고)
