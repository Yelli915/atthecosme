# 7. 파이프라인 코드 구현 (Stage 1~5)

- 상태: 진행중 (코드 작성 완료, 실제 이미지·벤치마크셋으로 미검증)
- 일시: 2026-09-24
- 계획.md 범위 밖 작업: 계획.md는 "코드가 이미 있다"는 전제로 사실 정리부터 시작했지만,
  실제로는 코드가 없었기 때문에(00-setup.md 참고) 이 단계에서 파이프라인 자체를 처음부터 구현했다.
  계획.md 1~6단계는 이 구현 이후에 진행한다.

## 스택 결정

| Stage | 선택 | 비고 |
| --- | --- | --- |
| 1. OCR | PaddleOCR (로컬) | `pipeline/ocr/engine.py` |
| 2. 하이브리드 검색 | SQLite + rank_bm25 + FAISS(sentence-transformers 임베딩) | `pipeline/retrieval/` |
| 3. 구조화 출력 | Ollama 로컬 LLM (`qwen2.5:7b`), JSON Schema `format` 파라미터로 Enum 제약 | `pipeline/structured_output/normalize.py` |
| 4. 대조 | 규칙 기반 ID 집합 비교 (누락/추가/불일치) | `pipeline/match/match.py` |
| 5. 신뢰도 분기 | 현재는 Stage 2 검색 점수만 사용 (임시), 임계치 0.90 플레이스홀더 | `pipeline/run.py`, `pipeline/config.py` |

## 만든 파일

```
requirements.txt
pipeline/config.py                     # 경로·모델명·임계치 전역 설정
pipeline/ocr/engine.py                 # Stage 1
pipeline/retrieval/db.py               # 성분 마스터 DB (SQLite)
pipeline/retrieval/bm25_index.py       # Stage 2 (BM25)
pipeline/retrieval/vector_index.py     # Stage 2 (FAISS)
pipeline/retrieval/hybrid.py           # Stage 2 (결합)
pipeline/structured_output/normalize.py # Stage 3
pipeline/match/match.py                # Stage 4
pipeline/run.py                        # Stage 1~5 오케스트레이션
eval/metrics.py                        # 재현율/정밀도/EM
eval/run_benchmark.py                  # 벤치마크 실행 스크립트
data/ingredient_db/seed_ingredients.csv # 샘플 15건 (실제 DB 아님, 동작 확인용)
data/benchmark/manifest.example.json    # 벤치마크 manifest 포맷 예시
.gitignore
```

## 확인한 것 (이번 세션에서 실제로 실행/검증)

- `python -m pipeline.retrieval.db` → SQLite DB 생성 및 15건 적재 확인 (`pipeline/retrieval/db.py`, stdlib만 사용해 의존성 설치 없이 검증 가능)
- 전체 `.py` 파일 `py_compile` 문법 검사 통과

## 아직 확인 못한 것 (의존성 미설치 · 실 데이터 없음)

- PaddleOCR / FAISS / sentence-transformers / Ollama — `pip install -r requirements.txt` 및 `ollama pull qwen2.5:7b` 미실행 상태라 Stage 1·2(Dense)·3 실제 동작 미검증
- 실제 라벨 이미지, 실제 성분 마스터 DB, 실제 벤치마크 manifest 전부 없음 → `eval/run_benchmark.py` 실행 불가
- Stage 5 신뢰도 결합에서 기획서가 언급한 "구조화 출력 토큰 로그 확률" 반영 안 함 — Ollama 응답에서 로그 확률을 받는 방법 확인 필요 (`pipeline/run.py` 주석 참고)
